# Tatsi in motion — 10 вариантов по референсу, 31–40

Каллиграфические t, антиквенные T, открытые орбиты и плавные ленты.
Каждый знак нарисован отдельными редактируемыми векторными контурами.

Откройте `applications.html`: наведение на номер показывает один вариант
на сайте и в Instagram. На телефоне используйте нажатие; доступны также
Tab, стрелки, Home и End. `preview/reference-31-40.png` — общий обзор.

- `svg/` — 10 основных SVG, белый + #bcf7f3, прозрачный фон.
- `svg-light/` — те же контуры для светлого фона: белый заменён на #142627.
- `applications/` — для каждого варианта общий макет, сайт и Instagram
  отдельными PNG; также исходный HTML макета.
- `tatsi-in-motion-31-40.zip` — автономная галерея, 20 SVG с двумя цветовыми
  версиями, 30 PNG макетов, обзор и эта инструкция.

В SVG нет встроенных картинок, шрифтов или внешних зависимостей.
Изменять цвет можно через `fill`, форму — через узлы контура.
Тёмный фон в галерее служит подложкой и не включён в SVG.

Нумерация продолжает существующие варианты 01–30, чтобы сохранить все наборы.
В макетах использованы фотографии существующего сайта. Instagram показан как
пример оформления; имя профиля условное, статистика не выдумана.
Материалы сохранены локально. Финальный логотип ещё предстоит выбрать.
