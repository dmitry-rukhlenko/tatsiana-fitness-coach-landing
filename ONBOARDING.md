# Как начать работать над сайтом вместе с Claude

Эта инструкция для Тани. Она написана для человека, который никогда не
программировал. Если какое-то слово непонятно, его объяснение есть в самом
начале, а всё остальное можно спрашивать у Claude.

Понадобится около 30–40 минут, компьютер с **Windows 10 или 11** и интернет.
Никаких команд вводить не нужно: только скачать три программы, нажать кнопки
и войти в аккаунт. Если у тебя Mac, загляни в самый конец — там отдельный
короткий раздел.

**Можно пройти вместе с Claude.** Вместе с этой инструкцией есть файл
`CLAUDE-SETUP.md` — это та же инструкция, но написанная для Claude. Сделай
сама Шаги 1–3 (без Git вкладка Code на Windows не запустится), потом открой
в Claude вкладку **Code**, начни новую сессию в любой папке, перетащи этот
файл в окно чата и напиши «Проведи меня по этой инструкции». Дальше Claude
будет вести по шагам и проверять, что всё получилось.

---

## Несколько слов, которые встретятся дальше

**Сайт** живёт в двух местах. Одна копия на **GitHub** — это сайт в
интернете, где хранятся файлы проекта и вся история их изменений. Вторая
копия будет у тебя на компьютере. Ты меняешь свою копию, потом отправляешь
изменения на GitHub, а Дмитрий их проверяет и публикует.

**Git** — программа, которая запоминает каждое изменение файлов. Благодаря
ей ничего нельзя испортить навсегда: любую правку можно откатить. Работает
незаметно, сама ты её открывать не будешь.

**GitHub Desktop** — программа с обычными окнами и кнопками, через которую
компьютер входит в твой GitHub и скачивает сайт.

**Claude Code** — вкладка «Code» в приложении Claude. Ты пишешь ей задачу
обычными словами («поменяй текст в блоке о консультации»), а Claude сам
находит нужный файл, правит его и показывает результат.

**Ветка** — отдельная «черновая копия» сайта для одной задачи. Ты работаешь в
черновике, а когда всё готово, Дмитрий переносит изменения на живой сайт.
Главная ветка называется **main** — это и есть живой сайт, поэтому её не
трогают напрямую (GitHub это и не позволит).

**Pull request** (читается «пул реквест», сокращённо PR) — просьба «перенесите
мой черновик на живой сайт». Дмитрий получает уведомление и проверяет.

Адрес живого сайта: <https://dmitry-rukhlenko.github.io/tatsiana-fitness-coach-landing/>

## Шаг 1. Завести аккаунт на GitHub (5 минут)

1. Открой в браузере <https://github.com/signup>.
2. Введи свою почту, придумай пароль и имя пользователя (логин). Логин
   пишется латиницей, например `tatsiana-r`. Его потом увидит Дмитрий.
3. Подтверди почту: GitHub пришлёт письмо с кодом.
4. **Напиши Дмитрию свой логин.** Он отправит тебе приглашение в проект.
5. Когда придёт письмо от GitHub со словами «invited you to collaborate»,
   открой его и нажми зелёную кнопку **Accept invitation**.

   Если письма нет, открой эту страницу и прими приглашение там:
   <https://github.com/dmitry-rukhlenko/tatsiana-fitness-coach-landing/invitations>

Можно идти дальше, даже если приглашение ещё не пришло. Скачать и
посмотреть сайт можно и без него; оно понадобится, только чтобы отправлять
изменения.

## Шаг 2. Установить приложение Claude (5 минут)

1. Открой <https://claude.ai/download> и скачай версию для Windows.
2. Запусти скачанный файл (он в папке «Загрузки») и дождись окончания
   установки. Если Windows спросит «Разрешить этому приложению вносить
   изменения?», нажми **Да**.
3. Запусти Claude и войди в свой аккаунт.
4. Для работы с сайтом нужна подписка Claude Pro или выше. Если её нет,
   скажи Дмитрию.

## Шаг 3. Установить Git (5 минут)

Git нужен Claude для работы с сайтом. Сама ты его открывать не будешь.

1. Открой <https://git-scm.com/downloads/win>.
2. Вверху страницы нажми первую ссылку на скачивание (64-bit, она же x64).
   Скачается файл с названием вроде `Git-2.xx-64-bit.exe`.
3. Запусти его. На вопрос Windows «Разрешить вносить изменения?» нажми **Да**.
4. Установщик покажет много экранов с настройками. **Ничего не меняй** —
   на каждом просто нажимай **Next**, в конце **Install**.
5. На последнем экране сними галочку «View Release Notes» и нажми **Finish**.

## Шаг 4. GitHub Desktop: войти и скачать сайт (10 минут)

1. Открой <https://desktop.github.com/download/> и нажми большую кнопку
   скачивания для Windows.
2. Запусти скачанный файл. GitHub Desktop установится сам, без вопросов, и
   сразу откроется.
3. **Войти в GitHub.** Нажми **Sign in to GitHub.com**. Откроется браузер:
   войди со своим логином и паролем GitHub, нажми зелёную кнопку
   **Authorize desktop**. Браузер спросит «Открыть GitHub Desktop?» —
   нажми **Открыть** (Open). Ты вернёшься в программу.
4. **Подпись для правок.** Программа покажет экран **Configure Git** с именем
   и почтой. Имя можно оставить как есть. Если в списке почт есть адрес,
   который заканчивается на `users.noreply.github.com`, выбери его — тогда
   твоя настоящая почта не будет видна публично. Нажми **Finish**.
5. **Скачать сайт.** В окне «Let's get started» выбери **Clone a repository
   from the Internet…** (если окна нет — меню **File → Clone repository…**).
6. Открой вкладку **URL** и вставь в верхнее поле:

   ```text
   dmitry-rukhlenko/tatsiana-fitness-coach-landing
   ```

7. Нижнее поле **Local path** не трогай: там уже стоит папка вида
   `C:\Users\<твоё имя>\Documents\GitHub\tatsiana-fitness-coach-landing`.
   Это и есть место, где будет лежать сайт. Нажми **Clone** и подожди
   минуту.

Готово: сайт у тебя на компьютере, в папке **Документы → GitHub →
tatsiana-fitness-coach-landing**. GitHub Desktop можно закрыть; позже в нём
удобно смотреть, что изменилось, но всю работу будет делать Claude.

## Шаг 5. Открыть сайт в Claude Code

1. В приложении Claude найди вкладку **Code** (обычно вверху или слева).
2. Claude попросит выбрать папку проекта. Выбери папку
   **Документы → GitHub → tatsiana-fitness-coach-landing**.
3. Теперь Claude видит все файлы сайта. Напиши ему первое сообщение:

```text
Прочитай ONBOARDING.md, PRODUCT.md и DESIGN.md и расскажи простыми словами,
что это за сайт, какие тут правила для текста и дизайна и как принято работать.
```

Claude ответит и дальше будет помогать. Можно спрашивать всё, что непонятно:
«что это за файл», «объясни это слово», «что ты сейчас сделал».

Чем файлы сайта отличаются друг от друга:

| Файл или папка | Что это |
| --- | --- |
| `index.html` | Главная страница, все тексты на немецком и английском |
| `style.css` | Внешний вид: цвета, шрифты, отступы |
| `script.js` | Поведение: переключение языка, форма заявки |
| `impressum.html` | Impressum и Datenschutz, обязательны для Германии |
| `images/` | Фотографии, которые видны на сайте |
| `demo/` | Три демо-варианта нового дизайна (A, B, C), на сайт пока не перенесены |
| `PRODUCT.md`, `DESIGN.md` | Описание бренда и правила дизайна |
| `ROADMAP.md` | Что нужно сделать до настоящего запуска |

Исходных фотографий (папка `original images`) на твоём компьютере не будет:
они намеренно не публикуются. Если понадобятся, Дмитрий передаст их отдельно.

## Шаг 6. Посмотреть сайт у себя на компьютере

Напиши Claude:

```text
Открой сайт в браузере, чтобы я посмотрела.
```

Это **твоя копия**: что бы ты в ней ни меняла, в интернете ничего не
изменится, пока Дмитрий не перенесёт твои правки на живой сайт. Если Windows
покажет окно брандмауэра «Разрешить доступ?», можно нажать «Разрешить» —
сайт открывается только на твоём компьютере.

## Шаг 7. Как делать правки

Одна задача — один черновик (ветка). Порядок всегда одинаковый, три
сообщения Claude.

**1. Начать задачу.** Напиши Claude:

```text
Переключись на main, подтяни последние изменения и создай новую ветку
для задачи: <тут коротко, что хочешь сделать>.
```

Claude сам придумает имя ветки, например `tanya/new-consultation-text`.

**2. Сказать, что поменять.** Обычными словами, как коллеге:

```text
В блоке о консультации на главной странице замени немецкий текст на: «...».
Английскую версию переведи сама и покажи мне перевод до того, как менять.
```

Claude покажет, что изменил. Открой сайт у себя (Шаг 6) и проверь глазами.
Не нравится — скажи, что поправить. Хочешь отменить — скажи «отмени
последнее изменение».

**3. Отправить Дмитрию на проверку:**

```text
Сохрани изменения с понятным описанием, отправь ветку на GitHub и помоги
создать pull request. В описании напиши, что изменилось и на что обратить
внимание.
```

**В самый первый раз** при отправке появится окошко **Connect to GitHub**
(или «Git Credential Manager»). Нажми **Sign in with your browser**, в
браузере нажми **Authorize**, вернись в Claude. Больше это окно не появится.

Потом Claude даст ссылку на страницу GitHub. Открой её и нажми зелёную
кнопку **Create pull request**. Дмитрий получит уведомление, посмотрит, при
необходимости попросит что-то поправить и опубликует. Через минуту после
публикации изменения видны на живом сайте.

**4. Следующая задача — снова с пункта 1.** Не продолжай старый черновик для
новой задачи.

## Что ещё можно говорить Claude

- «Покажи, что я изменила с прошлого раза».
- «Отмени все изменения в файле style.css».
- «Есть ли на GitHub что-то новое от Дмитрия? Подтяни».
- «Объясни простыми словами, что делает этот кусок».
- «Сделай скриншот сайта как на телефоне и как на компьютере».
- «Я запуталась. Расскажи, в какой я сейчас ветке и что не сохранено».

## Если что-то пошло не так

- **Claude пишет «Permission denied» или «403» при отправке на GitHub.**
  Приглашение ещё не принято (Шаг 1, пункт 5). Прими его и попроси Claude
  отправить ещё раз.
- **Вкладка Code пишет, что нужен Git.** Значит, Git не установлен или Claude
  открыт с тех времён, когда его ещё не было. Сделай Шаг 3, потом полностью
  закрой Claude (через значок возле часов в правом нижнем углу, если он там
  есть) и открой снова.
- **В GitHub Desktop ошибка при Clone.** Проверь интернет и нажми Clone ещё
  раз. Если папка уже существует, программа скажет об этом — тогда сайт уже
  скачан, переходи к Шагу 5.
- **Claude говорит про «конфликт» (merge conflict).** Значит, Дмитрий менял тот
  же файл. Скажи Claude: «есть конфликт, покажи оба варианта и помоги выбрать».
- **Что-то сломалось и непонятно что.** Пока Дмитрий не опубликовал твой pull
  request, живой сайт в полном порядке. Напиши Дмитрию, приложи скриншот.
  Самое худшее, что может случиться с твоей копией, — её придётся скачать
  заново через GitHub Desktop.

## Если у тебя Mac

Шаги 1, 2 и с 5 по 7 — те же. Вместо Шагов 3 и 4 есть скрипт, который всё
делает сам. Открой **Терминал** (`Cmd + пробел`, напиши «Терминал», `Enter`),
вставь эту строку и нажми `Enter`:

```bash
curl -fsSL https://raw.githubusercontent.com/dmitry-rukhlenko/tatsiana-fitness-coach-landing/main/setup-tanya.sh -o ~/Downloads/setup-tanya.sh && bash ~/Downloads/setup-tanya.sh
```

Скрипт объясняет каждый шаг по-русски. Он попросит пароль от Mac (при вводе
символы не видны, это нормально) и код на сайте GitHub. Сайт он скачает в
папку `Coding/tatsiana-fitness-coach-landing` в твоей домашней папке.
